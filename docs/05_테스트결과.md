### U05 문제 조사 — 2026-10-12

- 사용자 보고: 새로고침 후 9월19일에 “판매내역 없음”. 해당 날짜에 0건이 표시되는 것을 브라우저에서 확인했다.
- 9월18일로 조회하자 카페라떼 포장 **12개·단가4,800원·할인0원·수수료936원·순매출57,600원·남는 금액41,189원**이 저장돼 있었다. 원본 샘플의 해당 기록은13개였다.
- 월간 합계도 원본 대비 라떼1개 감소를 반영하고 있다. 현재 저장 내용은 안내한 신규9월19일 기록과 다르다. 사용자가 확인 답변을 준 이력은 보존하되 U02~U05를 다시 확인한다.
- 현재 관찰만으로 브라우저 저장 실패를 확정할 수 없다. 9월18일의 수량 수정은 남아 있고9월19일 신규 기록은 없다. 날짜 입력·신규 등록 과정을 다시 확인해 원인을 구분한다.
- 사용자 기록을 임의로 지우거나 초기 샘플로 덮어쓰지 않았다. 코드 변경 없이 화면의 날짜별·월간 기록을 확인했다.
- 다음 재확인: 새 판매 창의 판매일·메뉴·채널·수량·할인·수수료를 명시해 U02 신규 등록을 다시 안내한다. EPIC 1은 미완료로 유지한다.
- 재확인 편의를 위해 브라우저에 9월19일·카페라떼·포장·10개·단가4,800원·할인1,000원·수수료700원을 **미저장 입력 상태로 준비**했다. 미리보기47,000원·12,896원·33,404원을 확인했다. 저장 버튼은 사용자가 누른다. [저장 전 화면](test-assets/epic1-u02-recheck.jpg).
